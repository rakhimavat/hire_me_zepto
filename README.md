## What's This Chaos? 🤯
Ever seen AI spit out a LinkedIn reply like "Hey Customer Name, I'm Agent Name..."? Yeah, me too. This is a **hilarious-yet-useful demo** of *ReplyGuard*, a validation engine that catches brand-killing goofs in AI-generated support replies **before** they embarrass you publicly.

Built as a mock for Zepto Care (think quick grocery delivery drama). Enter a buggy AI draft, and BAM – it validates, fixes tone, blocks placeholders, and spits out a safe, human-sounding post. No more "tinyurl.com/ZeptoOops" disasters! 😂

## What It Does (The Funny Breakdown)
- **Placeholder Patrol 🕵️**: Spots "Customer Name" leaks faster than your boss spots your coffee breaks.
- **Tone Tamer 🐯**: Turns robotic rants into calm, "we got you" vibes.
- **Link Linter 🔗**: Bans shady shortlinks – because trust > clicks.
- **Fallback Hero 🦸**: If it fails? Safe mode activates. No public meltdowns.

Powered by vanilla JS, CSS wizardry (dark/light theme toggle FTW), and zero backend drama.

## Why I Built This (Real Talk) 💥
AI is dope for drafts, but public posts? One slip-up = Twitter roast. This shows how to layer **deterministic rules** on AI for safer customer love. Inspired by real support nightmares. (Zepto fans, holla!)

## Tech Stack (Keep It Simple, Stupid) 🛠️

- Responsive AF (mobile-friendly for on-the-go support peeps)
